# VIT Semester Result — React App

Simple responsive React app to calculate one-semester results for VIT students.

Features:
- Enter four subjects with MSE (out of 30) and ESE (out of 70)
- Automatic weighted calculation: MSE 30%, ESE 70%
- Shows total, percentage and overall grade

Quick start

```bash
cd vit-result
npm install
npm run dev
```

Open the dev server URL shown by Vite (usually http://localhost:5173).
